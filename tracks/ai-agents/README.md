# AI Agents Track — Future-Proof Your Career

**Don't fear agents replacing you. Learn to build them.**

This track maps **50 curated resources** (videos, books, repos, guides, papers, courses, newsletters) into a **structured, project-based path** — same format as Week 1 Docker. Everything you build integrates with **TaskFlow** and your **portfolio**.

---

## Philosophy

| Wrong approach | Our approach |
|----------------|--------------|
| Watch 50 videos randomly | 4 phases, 4 capstone projects |
| Read papers without code | Implement ReAct, RAG, MCP in Python |
| Tutorial hell | Ship TaskFlow AI Assistant to Git |
| Learn agents in isolation | Automate with GitHub Actions + Terraform |

**Your edge:** 4 years Python backend + AWS + Docker/DevOps. You build agents *in production systems*, not notebooks.
